웨더투두 개인정보 처리방침

시행일 2026년 10월 25일

웨더투두(이하 "앱")는 일정에 맞춰 날씨·미세먼지를 보여 주는 앱입니다. 회원가입이 없고, 가입 정보로 이름·전화번호·이메일을 요구하지 않습니다. 다만 이용자가 메모나 일정에 직접 적은 내용은 아래 기능을 쓸 때 서버로 보내질 수 있습니다. 이 방침은 앱이 서버에서 처리하는 정보와 그 처리 방법을 설명합니다.

1. 처리하는 정보와 목적

언제항목목적
서버 알림(아침 날씨·미세먼지 나쁨·기상특보)을 켠 경우푸시 토큰(알림을 받을 기기 주소), 알림 받을 지역(위치 권한을 허용했다면 현재 위치로 정한 지역 이름, 예: "부산 대신동"), 알림 설정, 아침 날씨 알림을 켠 경우 일정의 날짜·시간(제목은 보내지 않음)아침 날씨 알림, 미세먼지 나쁨 알림, 기상특보 알림 발송
옷차림 추천을 받는 경우일정 제목, 일정 시간, 일정 장소의 지역·좌표옷차림 추천 생성. 일정 제목은 일정 종류(운동 등) 판단에만 쓰고 저장하지 않음
메모로 일정을 추가하는 경우메모 내용, 앱이 만든 기기 ID와 접속 IP를 서버 비밀키로 바꾼 값(해시), 날짜, 사용 횟수메모를 일정으로 바꾸기, 하루 사용 횟수 제한. 메모 내용, 기기 ID·IP 원문은 사용 횟수 기록에 저장하지 않음
장소를 검색하는 경우검색어네이버 장소 검색 결과 제공. 저장하지 않음
앱이 서버에 접속할 때접속 IP, 접속 시각, 요청 주소(서버 접속 기록에 원문으로 남음)장애 대응, 보안 점검

2. 처리하지 않는 정보

  • 일정 제목·메모 등 일정 내용은 이 휴대폰에만 저장되고 서버에 보관하지 않습니다. 메모로 일정 추가에 적은 내용도 변환에만 쓰고 저장하지 않습니다.
  • 휴대폰의 현재 위치 좌표(GPS)는 휴대폰 안에서 가까운 측정소를 찾는 데만 쓰고, 좌표 자체는 서버로 보내지 않습니다. 다만 그렇게 정한 지역 이름은 서버 알림을 켠 경우 알림 받을 지역으로 서버에 저장됩니다(1번 표). 옷차림 추천을 받을 때는 이용자가 일정에 고른 장소의 좌표가 서버로 갑니다.

3. 보유 기간과 파기

  • 알림 기기 정보: 앱에서 알림을 끄면 바로 비활성으로 바뀝니다. 앱을 삭제하면 다음 알림을 보낸 뒤 전달 결과(약 15분~1시간 뒤 확인)에서 삭제된 기기로 확인될 때 비활성으로 바뀝니다. 비활성이 된 날부터 30일 뒤 삭제
  • 알림 발송 기록, 메모로 일정 추가 사용 횟수: 30일 뒤 삭제
  • 서버 접속 기록(IP 원문 포함): 웹 서버 기록은 14일, 앱 서버 기록은 30일 이내 자동 삭제

삭제는 매일 자동으로 하며, 데이터베이스에서 지워 되살릴 수 없게 합니다.

4. 외부 서비스 이용과 국외 이전

받는 곳보내는 정보이유
Expo (650 Industries, Inc., 미국, 알림 전송 서비스)푸시 토큰, 알림 문구휴대폰으로 알림 전달. 알림을 보낼 때마다 네트워크로 전송
Google Cloud (서울 리전)위 1번의 서버 처리 정보 전체서버 운영(보관 위탁)
Google LLC (Gemini API, 미국)메모로 일정 추가에 적은 메모 내용과 오늘 날짜. 보내기 전에 연락처·이메일·주민번호·카드·계좌번호·상세 주소는 지우고, 건강·법률·종교 등 민감한 단어는 가린 뒤 보냄(모든 민감한 내용이 가려지지는 않음)메모를 일정으로 바꾸기. 쓸 때마다 네트워크로 전송
네이버장소 검색어장소 검색. 지도는 앱이 네이버 지도를 직접 불러오며 네이버 정책을 따름

국외로 가는 정보(Expo, Gemini)에 대해:

  • 이전 시점과 방법: 알림을 보낼 때, 메모로 일정을 추가할 때마다 암호화된 네트워크(HTTPS)로 보냅니다.
  • 받는 곳의 보유 기간과 문의처: 각 회사의 개인정보 처리방침을 따릅니다. Expo expo.dev/privacy, Google policies.google.com/privacy
  • 거부 방법: 앱 설정에서 서버 알림(아침 날씨·미세먼지 나쁨·기상특보)을 끄면 Expo로 보내지 않습니다. 메모로 일정 추가를 쓰지 않으면 Gemini로 보내지 않습니다. 거부해도 일정 알림(휴대폰 안에서 동작)과 나머지 기능은 그대로 쓸 수 있습니다.

위 경우 외에는 정보를 다른 곳에 제공하지 않습니다.

5. 앱 접근 권한

  • 위치(선택): 가까운 측정소 찾기. 허용하지 않아도 지역을 직접 골라 쓸 수 있습니다.
  • 알림(선택): 날씨·미세먼지·기상특보 알림.
  • 권한은 휴대폰 설정 > 애플리케이션 > 웨더투두 > 권한에서 언제든 끌 수 있습니다.

6. 이용자의 권리

앱 설정에서 서버 알림을 끄면 서버의 알림 기기 정보가 바로 비활성으로 바뀌고, 그날부터 30일 뒤 삭제됩니다. 바로 삭제를 원하거나 처리 내역이 궁금하면 아래 문의처로 연락해 주세요.

7. 안전성 확보 조치

  • 앱과 서버 사이 통신은 HTTPS로 암호화합니다.
  • API 키 등 비밀값은 코드가 아닌 서버 설정에 보관합니다.
  • 메모로 일정 추가의 사용 횟수 기록에는 기기 ID·IP 원문 대신 서버 비밀키로 바꾼 값(HMAC 해시)만 저장합니다. 서버 접속 기록에는 IP 원문이 남으며 3번의 기간이 지나면 지웁니다.
