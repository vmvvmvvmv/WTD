웨더투두 개인정보 처리방침

시행일 2026년 10월 18일

웨더투두(이하 "앱")는 일정에 맞춰 날씨·미세먼지를 보여 주는 앱입니다. 회원가입이 없고, 이름·전화번호·이메일을 받지 않습니다. 이 방침은 앱이 서버에서 처리하는 정보와 그 처리 방법을 설명합니다.

1. 처리하는 정보와 목적

언제항목목적
알림을 켠 경우푸시 토큰(알림을 받을 기기 주소), 알림 받을 지역, 알림 설정, 아침 날씨 알림을 켠 경우 일정의 날짜·시간아침 날씨 알림, 미세먼지 나쁨 알림 발송
옷차림 추천을 받는 경우일정 제목, 일정 시간, 일정 장소의 지역·좌표옷차림 추천 생성. 일정 제목은 일정 종류(운동 등) 판단에만 쓰고 저장하지 않음
장소를 검색하는 경우검색어네이버 장소 검색 결과 제공. 저장하지 않음
AI 문장 추천을 받는 경우접속 IP를 되돌릴 수 없게 바꾼 값(해시), 날짜, 사용 횟수한 사람당 하루 사용 횟수 제한. IP 원문은 저장하지 않음
앱이 서버에 접속할 때접속 IP, 접속 시각, 요청 주소장애 대응, 보안 점검

2. 처리하지 않는 정보

  • 일정 제목·메모 등 일정 내용은 이 휴대폰에만 저장되고 서버에 보관하지 않습니다.
  • 휴대폰의 현재 위치(GPS)는 휴대폰 안에서 가까운 측정소를 찾는 데만 쓰고 서버로 보내지 않습니다.

3. 보유 기간과 파기

  • 알림 기기 정보: 알림을 끄거나 앱을 삭제해 알림이 전달되지 않으면 비활성으로 바뀌고, 그로부터 30일 뒤 삭제
  • 알림 발송 기록, AI 사용 횟수: 30일 뒤 삭제
  • 옷차림 추천 저장값(개인을 알아볼 수 있는 정보 없음): 유효 시간(최대 3시간)이 지나면 삭제
  • 서버 접속 기록: 30일 이내 자동 삭제

삭제는 매일 자동으로 하며, 데이터베이스에서 지워 되살릴 수 없게 합니다.

4. 외부 서비스 이용과 국외 이전

받는 곳보내는 정보이유
Expo (미국, 알림 전송 서비스)푸시 토큰, 알림 문구휴대폰으로 알림 전달. 알림을 보낼 때마다 네트워크로 전송
Amazon Web Services Lightsail (서울 리전)위 1번의 서버 처리 정보 전체서버 운영(보관 위탁)
네이버장소 검색어장소 검색. 지도는 앱이 네이버 지도를 직접 불러오며 네이버 정책을 따름
Google (Gemini)날씨 요약과 옷차림 규칙 결과만 전송(개인을 알아볼 수 있는 정보 없음)옷차림 설명 문장 생성

위 경우 외에는 정보를 다른 곳에 제공하지 않습니다.

5. 앱 접근 권한

  • 위치(선택): 가까운 측정소 찾기. 허용하지 않아도 지역을 직접 골라 쓸 수 있습니다.
  • 알림(선택): 날씨·미세먼지 알림.
  • 권한은 휴대폰 설정 > 애플리케이션 > 웨더투두 > 권한에서 언제든 끌 수 있습니다.

6. 이용자의 권리

앱 설정에서 알림을 끄면 서버의 알림 기기 정보가 비활성으로 바뀌고 30일 안에 삭제됩니다. 바로 삭제를 원하거나 처리 내역이 궁금하면 아래 문의처로 연락해 주세요.

7. 안전성 확보 조치

  • 앱과 서버 사이 통신은 HTTPS로 암호화합니다.
  • API 키 등 비밀값은 코드가 아닌 서버 설정에 보관합니다.
  • IP는 원문 대신 되돌릴 수 없게 바꾼 값만 저장합니다.
