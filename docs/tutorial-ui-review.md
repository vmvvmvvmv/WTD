# 튜토리얼 UI 개선 의견서

## 확인한 상태

- 환영 시트 → 홈 투어 → 캘린더 추가 버튼 팁의 화면 연결과 완료 상태 저장 코드를 확인함. 예보 조회가 끝난 뒤 홈 투어를 시작함. 시간별 예보가 있으면 5단계, 없으면 4단계임.
- 마지막 홈 안내 버튼을 누르면 캘린더가 열리고 추가 버튼 팁이 이어짐. 건너뛰기와 뒤로가기는 투어만 닫음. 2·3단계와 캘린더 팁의 안내 문구는 화면에서 가리키는 곳에 맞춰 고침.
- 안드로이드 기기에서 설정의 `튜토리얼 다시 보기`로 새 1/5 지역 변경·검색과 2/5 배너를 확인함. 3/5 시간별 예보 → 4/5 홈 탭 → 5/5 캘린더 탭 → 추가 버튼 팁까지 이어짐.

## 개선 의견

1. 강조 영역과 설명 카드가 떨어져 보였음. 처음에는 선·점으로 이었지만, 사용자 의견에 따라 작은 화살표로 되돌림.
2. 설명 카드의 20px 둥근 모서리와 기본 아이콘은 앱의 14px 카드·그림 아이콘과 결이 달랐음.
3. `1 / 3` 숫자만으로도 순서는 알 수 있지만, 남은 단계의 길이는 바로 보이지 않았음.
4. 2단계 강조 영역은 `활동 가이드·추천 옷차림·날씨 지도` 탭 전체를 보여 주지만 기존 문구는 앞의 두 기능만 말했음. 세 탭을 모두 소개하는 문구로 고침.

## 적용한 디자인

```text
   밝게 남겨 둔 영역
         ▲ 화살표
┌───────────────────┐
│ 1 / 5   ━━──────── │
│ 제목 · 짧은 설명    │
│ 건너뛰기       다음 │
└───────────────────┘
```

- 강조 영역은 주변만 어둡게 하고 테두리는 그리지 않음. 설명 카드의 작은 화살표는 그대로 대상을 가리킴.
- 설명 카드는 기존 앱 카드처럼 14px 모서리와 `bauhausColors`·`textColors`를 사용함. 화면 위치에 따라 카드가 강조 영역 위나 아래로 가는 기존 배치는 유지함.
- 단계 숫자 아래에 진행 막대를 넣음. 환영 시트의 아이콘은 다른 화면에서도 쓰는 `AppActionIcon`의 일정 그림으로 바꿈.
- 캘린더 첫 방문 팁은 주변 화면을 어둡게 덮지 않는 기존 방식 그대로 두고, 화살표만 같은 스타일로 씀.
- 홈 투어 강조 영역의 흰색·파란색 테두리를 제거함. 앱 화면 자체의 버튼·카드 테두리는 건드리지 않음.

## 스토리보드 문구 수정

- 맨 앞에 `지역 바꾸기·검색`을 넣음. 상단의 지역 이름과 지역 검색 버튼을 한 번에 보여 줌.
- 다음은 `날씨 배너`임. 현재 날씨·미세먼지와 옆으로 넘기는 정보 화면을 설명함.
- 홈의 세 탭을 함께 강조하는 단계는 `홈에서 골라 보기`로 바꿈. 활동 가이드·추천 옷차림·날씨 지도를 모두 본문에 적음.
- 캘린더 탭을 강조하는 단계는 `캘린더에서 일정 추가`로 바꿈. 마지막 버튼은 `캘린더로`이고, 누르면 캘린더의 추가 버튼 팁까지 이어짐. 다시 보기에서도 이 팁을 보여 줌.
- 캘린더 첫 방문 팁은 오른쪽 아래 추가 버튼을 누르라는 첫 행동을 안내함. 앞 단계의 설명을 반복하지 않음.
- 시간별 예보 조회가 끝났는데 항목이 없으면 누를 수 없는 오류 안내를 강조하지 않고 그 단계만 뺌. 지역·배너·홈 탭·캘린더 네 단계는 유지함.

## 확인할 것

- 이전 구성에서 안드로이드 기기(1440×3120)의 3단계 투어와 예보 없는 2단계 투어를 확인했음.
- 새 구성에서는 안드로이드 기기에서 지역 1/5, 배너 2/5의 강조 위치와 화살표를 사진으로 확인함. 3/5~5/5 순서와 캘린더 팁도 기기에서 확인함.
- 새 구성의 예보 없는 4단계 흐름은 [확인 필요].
- 작은 화면과 글자 크게 보기에서 설명 카드·화살표가 강조 영역이나 화면 밖으로 겹치지 않는지 [확인 필요].
- iOS에서 밝게 남긴 강조 영역과 화살표가 실제 버튼을 정확히 가리키는지 [확인 필요].
- 안드로이드 기기에서 5/5 `캘린더로`를 누른 뒤 캘린더가 열리고 추가 버튼 팁이 뜨는 것을 확인함.
- 환영 시트의 이번 디자인 변경 뒤 실기기 화면은 [확인 필요]. 첫 설치 직후의 자동 팁 흐름은 [확인 필요].
- 튜토리얼 완료 상태 저장 방식은 유지함. 마지막 버튼의 화면 이동만 추가함.

사진 자리 — 새 지역 1/5와 배너 2/5 화면을 안드로이드 기기에서 캡처함. 3/5~5/5와 예보 없는 4단계 화면은 별도로 촬영함 [확인 필요].
